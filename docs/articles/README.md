## 目录约定

```text
docs/articles/
└── Vibe-Coding-全栈实战-章鱼哥解题-02-教材入库与检索基线/
    ├── index.md
    └── assets/
        └── image-name.png
```

Markdown 中引用图片时，统一使用相对路径：

```md
![图片说明](assets/image-name.png)
```
