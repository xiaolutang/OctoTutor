# OctoTutor

## 项目名称

**中文名**：章鱼哥解题
**英文名**：OctoTutor

## 名字含义

- **章鱼哥**：章鱼拥有八条触手，象征着强大的并行处理能力——同时应对多道数学题，算力爆表。戴着眼镜的章鱼形象，既聪明又可爱。
- **OctoTutor**：Octo（八爪）+ Tutor（导师），简洁好记，寓意"八臂导师，全方位辅导"。
- **Slogan**：八臂齐开，难题自然解开。

## 项目简介

基于高中数学的智能教学助手，帮助高中生更高效地学习数学。
