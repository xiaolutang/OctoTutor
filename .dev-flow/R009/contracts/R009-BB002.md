## 备注
- **AC7 时序偏差**：AC 描述"done 后更新 updated_at 和 message_count"，但代码中 `update_message_stats`（L92-96）在 yield done 帧（L98）**之前**执行。实际语义是"在 graph 完成后、发送 done 帧前更新统计"，而非"done 帧发出后更新"。这不影响最终数据正确性，但与 AC 字面描述有差异。如果 AC 严格要求"done 后"，需调整代码顺序（将 update_message_stats 移到 done yield 之后）。当前实现是先更新统计、再通知前端 done，语义上也合理。
- 新对话的 conversation 记录在 graph.astream 之前创建并 commit，确保 graph 执行过程中记录已持久化
- title 帧是 SSE 流中 done 之后的最后一个帧，前端可据此更新 UI 显示标题
- SSE title 帧格式：`event: title\ndata: {"conversation_id": "...", "title": "..."}\n\n`
- generator.generate_title 返回 None 或空字符串时不推送 title 帧（L105 `if title:` 判断）
