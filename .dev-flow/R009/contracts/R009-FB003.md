## Architecture Notes

```
ChatUI
  └─ useChatController()
       ├─ useConversationContext() → activeId, isNewConversation, insertNewConversation, updateTitle
       ├─ useChatStream() → sendMessage, stop, isStreaming
       └─ useConversation() → loadConversation(conversationId)
```

- ConversationContext (sessionStorage) 持有 activeId
- controller 监听 activeId 变化触发 loadConversation
- SSE onInit → insertNewConversation (新对话时)
- SSE onTitle → updateTitle
- isStreaming 同步到 ConversationContext (供 sidebar 使用)
