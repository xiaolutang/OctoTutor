## Implementation Plan

### 1. LLM Judge (backend/app/evaluation/graders/llm_judge.py)
- `LLMJudge` class, constructor: `api_key: str, base_url: str, model: str = "glm-5.1"`
- `judge(answer: str, context: str, key_facts: list[str]) -> JudgeResult`
  - 使用 OpenAI compatible client (同 infra/llm.py 模式)
  - Prompt: Faithfulness + Coverage 合并评估（含 Unknown 选项）
  - 解析 JSON 输出: claims[{claim, verdict}], coverage[{fact, status}]
- `JudgeResult` dataclass: claims (list), coverage (list), faithfulness (float), coverage_score (float), unknown_ratio (float)
- LLM 调用异常时抛出 RuntimeError

### 2. eval_runner.py 扩展
- EvalRunner 构造器新增可选参数: `reranker: Reranker | None = None, generator: Generator | None = None, settings: Settings | None = None`
- 新增 `run_context_precision(eval_filename) -> ContextPrecisionReport`
  - 对每个 item: 检索 top-K，计算 section_id 匹配的 Precision@K
  - Precision@K = (匹配的 truth source 数) / K
- 新增 `run_faithfulness(eval_filename) -> FaithfulnessReport`
  - 需 reranker + generator，缺失时 RuntimeError
  - 管线: 检索 → RRF → Rerank → Generate → DeterministicGrader → LLMJudge
  - 输出 Faithfulness + Coverage + Unknown 比例
- 新增 `run_regression(eval_filename) -> EvalReport`
  - 调用现有 run() 方法，只筛选 suite="regression" 的 items
- 新增 `run_full(eval_filename) -> FullEvalReport`
  - 需 reranker + generator
  - 汇总 regression + context_precision + faithfulness 结果

### 3. 新数据模型 (在 eval_runner.py 中定义)
- `ContextPrecisionReport`: overall_precision, per_item_details
- `FaithfulnessReport`: overall_faithfulness, overall_coverage, unknown_ratio, per_item_details
- `FullEvalReport`: regression_report, context_precision_report, faithfulness_report
- 所有 report 含 `to_dict()` 方法

### 4. 单元测试
- backend/tests/test_llm_judge.py — mock LLM response, 测试 Faithfulness/Coverage/Unknown 解析
- backend/tests/test_eval_runner_extended.py — 测试 4 个新 run 方法
- 测试 EvalRunner 缺少依赖时 RuntimeError
- 测试 run_regression 只筛选 suite="regression" 的 items

## Acceptance Criteria (Negotiated)
1. LLMJudge 正确解析 Faithfulness (Yes/No/Unknown) 和 Coverage (covered/not_covered/partially_covered)
2. Unknown claims 不计入 Faithfulness 分子分母，单独统计比例
3. run_context_precision 输出 Precision@K 数值 (0-1)
4. run_faithfulness 输出 Faithfulness + Coverage + Unknown 比例
5. run_regression 筛选 suite="regression" 的 items 并复用现有 run()
6. run_full 汇总所有指标
7. EvalRunner 缺 reranker/generator 时 run_faithfulness/run_full 抛 RuntimeError
8. 现有 run() 方法不受影响
9. 单元测试全部通过
