## 4. 技术规格

### 4.1 config.py 新增字段

```python
# JWT 鉴权 — 与 auth-center 共享密钥（HS256）
auth_jwt_secret: str = Field(
    ...,
    alias="JWT_SECRET_KEY",
    description="JWT 签名密钥，与 auth-center 共享（HS256）",
)
```

- 字段插入位置：在 `dashscope_embedding_dimension` 之后、`newapi_api_key` 之前
- `Field(...)` 表示必填，启动时缺少 `JWT_SECRET_KEY` 环境变量会抛 pydantic `ValidationError`
- `alias="JWT_SECRET_KEY"` 使环境变量名与 auth-center 对齐

### 4.2 middleware/auth.py 核心逻辑

```
UserContext = @dataclass(frozen=True)
  - user_id: str
  - username: str

get_current_user(request, credentials) -> UserContext:
  1. credentials is None → 401 "Missing authentication token"
  2. jwt.decode(token, secret, algorithms=["HS256"]) → JWTError → 401 "Invalid token: {exc}"
  3. payload["type"] != "access" → 401 "Invalid token type, expected 'access'"
  4. payload["sub"] 缺失或空 → 401 "Token missing subject (sub)"
  5. return UserContext(user_id=sub, username=client_id or sub)
```

- `_bearer_scheme = HTTPBearer(auto_error=False)` — 不自动报错，手动处理
- 所有 401 响应携带 `WWW-Authenticate: Bearer` header
- `ALGORITHM = "HS256"` 常量

### 4.3 JWT Payload 结构（auth-center 签发，后端只读验证）

```json
{
  "sub": "user_id_string",
  "client_id": "username_or_client_name",
  "exp": 1719360000,
  "type": "access"
}
```

### 4.4 requirements.txt 新增

```
# JWT 鉴权
python-jose[cryptography]>=3.3.0
```
