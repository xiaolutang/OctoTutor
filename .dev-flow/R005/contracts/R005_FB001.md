## Behavior Contract
1. **状态管理**: messages[], input, isStreaming 由 ChatUI 管理
2. **handleSend**: 创建 user 消息 + ai(retrieving) 消息 → sendMessage
3. **onError code='00000'**: 撤回最后 user+ai 消息，内容回填输入框
4. **onError 其他 code**: 标记 ai 消息 status='error' + error 字段
5. **handleStop**: 调用 stop()，覆盖 retrieving/generating 阶段
6. **持久化**: useEffect 客户端加载 loadMessages；done/stopped/error 时 saveMessages
