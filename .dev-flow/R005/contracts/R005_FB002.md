## 2. Implementation Plan

### 2.1 安装依赖

```bash
cd frontend && npm install react-markdown remark-math rehype-katex katex
```

新增依赖:
- `react-markdown`: Markdown 渲染
- `remark-math`: 数学公式解析
- `rehype-katex`: KaTeX 渲染
- `katex`: KaTeX 核心库

### 2.2 SourceCard 组件 (`source-card.tsx`)

```
Props: { sources: SourceReference[] }
State: expanded: boolean (默认 false)
渲染:
  - 收起时: "查看来源 (N)" 按钮
  - 展开时: 列表显示 book + section + page_start~page_end + 收起按钮
```

### 2.3 MessageBubble 增强 (`message-bubble.tsx`)

变更点:
1. AI 消息内容使用 `react-markdown` + `remark-math` + `rehype-katex` 渲染
2. KaTeX 配置: `throwOnError: false`
3. AI 消息底部显示 `<SourceCard sources={msg.sources} />` (有 sources 时)
4. AI 消息操作按钮组 (hover 显示): 复制 + 重新生成
5. 用户消息操作按钮组 (hover 显示): 编辑
6. 新增 Props: `onRegenerate`, `onEdit`, `onCopy`

### 2.4 ChatUI 增强 (`chat-ui.tsx`)

新增 Props 传递:
1. `handleRegenerate(messageId)`: 删除该 AI 消息 → 重新发起 SSE
2. `handleEdit(messageId)`: 删除该用户消息及后续所有消息 → 原文放回输入框
3. KaTeX CSS: `import 'katex/dist/katex.min.css'`
4. saveMessages 在 done/stopped/error 时已实现 (FB001)，无需变更

### 2.5 测试覆盖

| 测试 | 验证点 |
|------|--------|
| SourceCard 默认收起 | expanded=false, 显示"查看来源" |
| SourceCard 点击展开 | expanded=true, 显示来源详情 |
| handleRegenerate | 删除旧 AI 消息，重新发起 SSE |
| handleEdit | 删除后续消息，原文放回输入框 |
