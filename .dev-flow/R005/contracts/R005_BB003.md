## Domain

新建 `app/chat/stream_router.py` SSE 端点路由，将 ChatService.stream_chat() 的结构化 StreamEvent 序列化为 SSE 文本协议，注册到 FastAPI 应用，并更新 architecture.md。

**核心约束**：
- SSE 事件格式固定：`event: {type}\ndata: {json}\n\n`
- 5 种事件类型：status / sources / token / done / error
- 序列化策略：Pydantic BaseModel → model_dump()、dataclass → asdict()、list → 递归处理、原始值直传
- 断线检测：每轮迭代检查 `http_request.is_disconnected()`，断线 break 不 yield error
- 外层 try/except 兜底：不可预期的异常 yield INTERNAL_ERROR error event
- 保留原有 POST /api/chat 非流式端点不删除（DEC-chatui-002）
- 与 stream_router.py 独立文件，不修改 router.py（DEC-chatui-001）

## Implementation Plan

### Step 1. 新建 stream_router.py — SSE 端点路由

**文件**: `backend/app/chat/stream_router.py`（新建）

```python
import asyncio
import json
from dataclasses import asdict

from fastapi import APIRouter, Depends, Request
from fastapi.responses import StreamingResponse

from app.chat.schemas import ChatRequest
from app.chat.errors import ChatErrorCode, make_error
from app.chat.service import ChatService
from app.chat.dependencies import get_chat_service

router = APIRouter(prefix="/api", tags=["chat"])


@router.post("/chat/stream")
async def stream_chat(
    body: ChatRequest,
    http_request: Request,
    service: ChatService = Depends(get_chat_service),
):
    async def event_generator():
        try:
            async for event in service.stream_chat(body.question, body.top_k):
                if await http_request.is_disconnected():
                    break
                # 序列化 data
                data = event.data
                if hasattr(data, "model_dump"):
                    serialized = data.model_dump()
                elif hasattr(data, "__dataclass_fields__"):
                    serialized = asdict(data)
                elif isinstance(data, list):
                    serialized = [
                        item.model_dump()
                        if hasattr(item, "model_dump")
                        else asdict(item)
                        if hasattr(item, "__dataclass_fields__")
                        else item
                        for item in data
                    ]
                else:
                    serialized = data
                yield f"event: {event.type}\ndata: {json.dumps(serialized, ensure_ascii=False)}\n\n"
                await asyncio.sleep(0)
        except Exception:
            yield f"event: error\ndata: {json.dumps(make_error(ChatErrorCode.INTERNAL_ERROR), ensure_ascii=False)}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

**要点**：
- 独立文件 `stream_router.py`，与 `router.py`（POST /api/chat 非流式）不冲突
- 复用 ChatRequest（BF001 定义，question + top_k 字段不变）
- 复用 get_chat_service 依赖注入（BF001 定义的 dependencies.py）
- event_generator 是 async generator，由 StreamingResponse 惰性驱动
- 序列化优先级：Pydantic model_dump() → dataclass asdict() → list 递归 → 原始值直传
- `await asyncio.sleep(0)` 让出事件循环，允许其他请求处理
- 断线 break 后不 yield error event（用户主动停止，非错误）
- 外层 try/except 兜底捕获不可预期异常，yield INTERNAL_ERROR
