### 接口设计

#### SpotCheckResult 数据类
```python
@dataclass
class PageRangeCheck:
    book: str
    min_page: int
    max_page: int
    expected_max: int | None  # None 表示无法获取 PDF 页数
    passed: bool
    detail: str

@dataclass
class ContentCheck:
    book: str
    page: int
    chunks_found: int
    has_content: bool
    passed: bool
    detail: str

@dataclass
class ParentChildCheck:
    parent_id: str
    child_count: int
    passed: bool
    detail: str

@dataclass
class MetadataCheck:
    chunk_id: str
    missing_fields: list[str]
    passed: bool
    detail: str

@dataclass
class SpotCheckSummary:
    total_books: int
    total_chunks: int
    page_range_checks: list[PageRangeCheck]
    content_checks: list[ContentCheck]
    parent_child_checks: list[ParentChildCheck]
    metadata_checks: list[MetadataCheck]
    all_passed: bool
    duration_seconds: float
```

#### SpotChecker 类
```python
class SpotChecker:
    def __init__(
        self,
        vector_store: ChromaDBStore,
        sample_pages: int = 3,
    ) -> None:
        """
        Args:
            vector_store: ChromaDB 向量存储
            sample_pages: 每本书抽查的页数，默认 3
        """
        ...

    def run(self) -> SpotCheckSummary:
        """执行抽检

        流程:
        1. 从 ChromaDB 获取所有 chunk 的元数据
        2. 按书分组，检查页码范围
        3. 每本书抽查 sample_pages 页，验证内容非空
        4. 验证 Parent-Child 分块结构
        5. 验证元数据字段完整性
        6. 汇总输出 SpotCheckSummary
        """
        ...
```

### 抽检流程
```
1. vector_store 获取全部数据（通过 query 全量拉取）
2. 按书分组:
   a. 检查每本书 min(page) 和 max(page)，输出 PageRangeCheck
   b. 随机/均匀选取 sample_pages 页，查询该页 chunks，验证内容非空 → ContentCheck
   c. 收集所有 parent 类型 chunk，验证每个 parent 至少有 1 个 child → ParentChildCheck
   d. 对所有 chunk 验证 metadata 字段（book, chapter, section, page）非空 → MetadataCheck
3. 汇总输出 SpotCheckSummary
```

## risk_negotiation

| 风险标签 | 风险描述 | 缓解措施 |
|---------|---------|---------|
| empty_store | ChromaDB 为空时抽检无数据 | 空库返回 total_books=0, total_chunks=0, all_passed=True |
| chromadb_query_limit | ChromaDB query 有 top_k 限制，无法一次性拉全量 | 使用 collection.get() 替代 query 直接获取全部数据 |
| metadata_type | ChromaDB 存储的 metadata 类型可能不一致 | 统一类型转换（int(page), bool(has_formula)） |
| page_range | 无法获取 PDF 实际页数时只验证内部一致性 | expected_max 设为 None，仅检查 min >= 1 |
