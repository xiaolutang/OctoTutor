## 实现详情

### POST /api/retrieve
- Request Model: RetrieveRequest(query: str, top_k: int = 5, ge=1, le=20)
- Response Model: RetrieveResponse(chunks: list[ChunkResponse], total: int)
- ChunkResponse: chunk_id, text, score, metadata(dict)
- 处理流程: query → embed_query → ChromaDBStore.query → 映射为响应
- Embedding 失败 → 500, ChromaDB 失败 → 500
- 缺 query / 空 query / top_k 超范围 → 422（Pydantic 自动校验）

### GET /api/health（扩展版）
- Response: {status, chromadb: {connected, document_count}, embedding: {available}}
- ChromaDB 连接检测: 调用 store.count()，异常时 connected=false
- Embedding 检测: 检查 embedding_service 非 None
- 整体状态: connected=true → healthy, false → unhealthy

### 依赖注入
- lifespan 中初始化 ChromaDBStore + DashScopeEmbedding 单例
- 通过 app.state 存储，路由通过 Depends() 获取
- 测试中手动设置 app.state 替换为 mock
