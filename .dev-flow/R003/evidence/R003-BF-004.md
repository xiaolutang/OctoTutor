## 新增文件

### 1. `services/backend/app/rag/models.py`
- SectionBoundary: 章节边界数据类（title, level, start_pos, end_pos, page, section_index）
- ChunkMetadata: 分块元数据（book, chapter, section, page, chunk_type, has_formula, parent_id, child_index）
- Chunk: 分块结果（chunk_id, text, metadata）
- ChunkMetadata.to_dict(): 转换为 ChromaDB 存储格式

### 2. `services/backend/app/rag/chunkers/__init__.py`
- 空包初始化文件

### 3. `services/backend/app/rag/chunkers/math_chunker.py`
- StructureParser: 章节标题正则识别
  - 第X章 → level=1
  - X.X → level=2
  - 习题/练习X.X → level=3
  - X.X.X → level=4
  - 支持有/无 Markdown # 标记的标题
  - 层级感知的 end_pos 计算（子节不截断父节范围）
- MathChunker: Parent-Child 分块
  - Parent = level=2 小节完整内容
  - Child = 512 token (~1024 字符), 50 token (~100 字符) 重叠
  - 句子边界切分（句号/问号/感叹号/换行）
  - 单句超限整个保留
  - Chunk ID 按规则生成
- 辅助函数: _clean_section_title, _has_formula, _remove_title_line, _split_sentences

### 4. `services/backend/tests/test_chunker.py`
- 39 个测试用例，4 个测试类
