## 设计决策记录

### main.py 使用 lifespan 替代 @app.on_event("startup")
- Contract 中使用了已废弃的 `@app.on_event("startup")`
- 实现时改为 FastAPI 推荐的 `lifespan` 上下文管理器模式
- 理由：`on_event` 在最新 FastAPI 中标记为 deprecated，lifespan 是官方推荐方式

### conftest.py 使用 @pytest_asyncio.fixture
- pytest-asyncio strict mode 下 `@pytest.fixture` 不支持 async fixture
- 改用 `@pytest_asyncio.fixture` 装饰器解决兼容性问题

### health.py 动态读取 version
- Contract 中 health 端点硬编码了 version 字符串
- 改为从 `settings.app_version` 读取，保持单一数据源

### .gitignore 覆盖根目录 .env* 规则
- 根目录 `.gitignore` 有 `.env*` 规则，会忽略 `.env.template`
- 在 backend `.gitignore` 中添加 `!.env.template` negation 规则解决

### data/ 子目录 gitkeep 策略
- 使用 `data/subdir/*` + `!data/subdir/.gitkeep` 模式
- 忽略数据文件但保留目录结构和 `.gitkeep`，确保空目录被 git 追踪
