## 实现详情

### VectorStore Protocol
- 定义 `upsert(chunks, embeddings)` / `query(query_embedding, top_k, where)` / `delete(where)` 三个方法
- 使用 `@runtime_checkable` 装饰器，支持 `isinstance` 检查

### ChromaDBStore
- 基于 `chromadb.PersistentClient`，数据持久化到可配置目录
- 默认 collection: `octotutor_chunks`，距离度量: cosine
- upsert: 批量插入 chunks + embeddings + metadatas，支持幂等
- query: 输入 embedding + top_k + where → 返回 `QueryResult[]`（score = 1 - distance）
- delete: 按 where 条件删除
- count: 返回文档数量
- 支持所有 ChromaDB where 语法（精确匹配、范围、$and 组合）

### QueryResult
- chunk_id, text, metadata(ChunkMetadata), score(float)
