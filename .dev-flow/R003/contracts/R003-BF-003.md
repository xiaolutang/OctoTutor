```python
class PDFReader:
    """PDF 读取模块，支持全量 OCR + 缓存优先

    核心流程（逐页）:
    1. 检查 data/parsed/{book}/page_{N}.md 是否存在
    2. 有缓存 → 直接读取内容
    3. 无缓存 → PyMuPDF 渲染 PNG → 调 DashScope OCR → 存缓存到 parsed/
    4. PNG 存入 data/images/{book}/page_{N}.png（仅无缓存时渲染）

    Args:
        parsed_dir: OCR 缓存根目录 (data/parsed)
        images_dir: 页面图片根目录 (data/images)
        api_key: DashScope API Key
        dpi: PNG 渲染 DPI，默认 150
        max_retries: OCR 失败重试次数，默认 2
    """

    def __init__(self, parsed_dir, images_dir, api_key, dpi=150, max_retries=2):
        ...

    def read_pdf(self, pdf_path: str) -> list[PageResult]:
        """读取 PDF 全部页面

        Args:
            pdf_path: PDF 文件路径

        Returns:
            PageResult 列表，每页包含 page_number, content, from_cache
        """

    def read_page(self, pdf_path: str, page_number: int) -> PageResult:
        """读取单页

        Args:
            pdf_path: PDF 文件路径
            page_number: 页码（1-based）

        Returns:
            PageResult
        """

    def _check_cache(self, book_name: str, page_number: int) -> str | None:
        """检查缓存文件是否存在，存在则返回内容"""

    def _render_png(self, page, book_name: str, page_number: int) -> str:
        """PyMuPDF 渲染页面为 PNG，存入 images 目录"""

    def _ocr_page(self, image_path: str) -> str:
        """调用 DashScope 多模态 OCR，返回 Markdown+LaTeX 文本"""

    def _save_cache(self, book_name: str, page_number: int, content: str) -> None:
        """保存 OCR 结果到缓存文件"""
```

数据结构:
```python
@dataclass
class PageResult:
    page_number: int       # 1-based 页码
    content: str           # OCR 后的 Markdown+LaTeX 内容
    from_cache: bool       # 是否来自缓存
    image_path: str | None # PNG 路径（仅无缓存时有值）
```

#### Step 3: 编写单元测试 tests/test_pdf_reader.py

### 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| OCR 失败 | 重试 2 次，仍失败则跳过该页（content=""），记录日志 |
| PNG 渲染失败 | 跳过该页，记录日志 |
| 缓存写入失败 | 不阻塞，记录日志，继续处理 |
| PDF 文件不存在 | 抛出 FileNotFoundError |
| PDF 文件无法打开 | 抛出 RuntimeError |
