### 入库流程
```
1. _scan_pdfs() 扫描 data/raw/ 下的 PDF 文件
2. 对每本 PDF:
   a. ChromaDBStore.delete(where={"book": book_name}) 删除旧数据（幂等）
   b. PDFReader.read_pdf() 逐页处理（OCR 缓存优先）
   c. 汇总所有页面 Markdown → 全文
   d. StructureParser.parse() 识别章节
   e. MathChunker.chunk() 分块 → Chunk[]
   f. EmbeddingService.embed() 批量 embed 所有 Chunk.text
   g. ChromaDBStore.upsert(chunks, embeddings)
3. 汇总输出 IngestionStats
```

### 幂等策略
- 入库前 ChromaDBStore.delete(where={"book": book_name}) 删除旧数据
- OCR 缓存天然幂等（parsed/ 目录已有缓存跳过 OCR）
- 重复运行结果一致：chunks 数量不变

## risk_negotiation

| 风险标签 | 风险描述 | 缓解措施 |
|---------|---------|---------|
| network | DashScope OCR/Embedding API 可能超时或限流 | PDFReader 内置重试；EmbeddingService 内置重试；失败记录 errors 不阻塞 |
| startup | ChromaDB 初始化可能影响启动速度 | ChromaDBStore 构造函数内 get_or_create_collection，通常毫秒级 |
| pdf_corrupt | PDF 文件可能损坏 | PDFReader 已有 try/except 处理，返回空 content |
| disk_space | 大量 PDF 全量入库可能占用磁盘 | ChromaDB 嵌入式存储，5 本教材预计 <500MB |
| memory | 全量入库时所有 chunks 在内存中 | 按书处理，每本书处理完即 upsert，内存可控 |
