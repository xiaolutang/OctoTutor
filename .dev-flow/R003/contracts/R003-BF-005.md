#### 算法设计

##### 批量分片逻辑
```
输入: texts[], batch_size=6
1. 将 texts 按 batch_size 分片 → batches[]
2. 对每个 batch 调用 DashScope API
3. 按 text_index 排序收集结果
4. 拼接所有 batch 的结果 → 最终 embeddings[]
```

##### 指数退避重试逻辑
```
对每个 batch 调用:
  for attempt in range(max_retries + 1):  # 0, 1, 2, 3
    try:
      response = TextEmbedding.call(model, input=batch, ...)
      if response.status_code == 200:
        return embeddings
      else:
        raise RuntimeError(f"API error: {response.code} - {response.message}")
    except Exception:
      if attempt < max_retries:
        wait = 2^attempt 秒 (1, 2, 4)
        sleep(wait)
      else:
        raise
```

## risk_negotiation

| 风险标签 | 风险描述 | 缓解措施 |
|---------|---------|---------|
| network | DashScope API 调用可能因网络问题失败 | 指数退避重试 3 次（1s, 2s, 4s），总等待 7 秒 |
| api_limit | DashScope Embedding API 批量上限为 6 条 | 默认 batch_size=6，自动分片 |
| api_key | API Key 缺失或无效导致启动失败 | 在 __init__ 中设置 api_key，测试中通过 mock 避免 |
| dimension | 模型返回维度可能与预期不符 | 验证返回向量维度，不一致时抛出异常 |
