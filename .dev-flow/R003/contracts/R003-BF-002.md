#### Step 3: 编写 app/config.py（pydantic-settings）
```python
from pydantic_settings import BaseSettings
from pydantic import Field

class Settings(BaseSettings):
    """应用配置，从环境变量 / .env 文件加载"""

    # 应用基础
    app_name: str = "OctoTutor-API"
    app_version: str = "0.1.0"
    debug: bool = False

    # DashScope
    dashscope_api_key: str = Field(
        ...,
        description="DashScope API Key，用于 Embedding 和 OCR"
    )
    dashscope_embedding_model: str = "text-embedding-v3"
    dashscope_embedding_dimension: int = 768

    # ChromaDB
    chroma_persist_dir: str = "data/chroma_db"

    # 数据目录
    data_raw_dir: str = "data/raw"
    data_parsed_dir: str = "data/parsed"
    data_images_dir: str = "data/images"

    model_config = {
        "env_file": ".env",
        "env_file_encoding": "utf-8",
        "extra": "ignore",
    }

settings = Settings()
```

关键设计决策：
- `dashscope_api_key` 是必填字段（无默认值），缺少时启动报 ValidationError
- 所有数据目录使用相对路径，相对于 `services/backend/` 工作目录
- `extra = "ignore"` 允许 .env 中有额外变量不报错

def test_config_missing_dashscope_key_raises():
    """缺少 DASHSCOPE_API_KEY 时启动报错"""
    from pydantic_settings import BaseSettings
    from pydantic import Field

    class TestSettings(BaseSettings):
        dashscope_api_key: str = Field(...)

    import os
    # 临时删除环境变量
    key = "DASHSCOPE_API_KEY"
    original = os.environ.pop(key, None)
    try:
        with pytest.raises(ValidationError):
            TestSettings()
    finally:

            os.environ[key] = original

## contract_alignment

### GET /api/health 契约对齐说明

api_contracts.md 定义了完整的 health 响应格式：
```json
{
  "status": "healthy",
  "chromadb": {"connected": true, "document_count": 3420},
  "embedding": {"available": true}
}
```

BF-002 阶段实现**简化版本**，仅返回：
```json
{
  "status": "healthy",
  "version": "0.1.0"
}
```

理由：
1. BF-002 是脚手架任务，ChromaDB 和 Embedding 模块尚未实现
2. 返回 `chromadb: {connected: false}` 会误导调用方
3. R003-BB-008 会扩展此端点，添加 chromadb 和 embedding 字段，最终符合 api_contracts.md 的完整定义
4. 额外添加 `version` 字段是脚手架阶段的有用信息，BB-008 时可保留或移除

### 契约演进路径
- BF-002: `{"status": "healthy", "version": "0.1.0"}`
- BB-008: `{"status": "healthy", "chromadb": {...}, "embedding": {...}}` （完整契约）
