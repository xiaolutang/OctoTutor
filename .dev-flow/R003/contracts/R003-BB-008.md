### 接口设计

#### POST /api/retrieve

**Request (Pydantic Model)**:
```python
class RetrieveRequest(BaseModel):
    query: str = Field(..., min_length=1, description="查询文本")
    top_k: int = Field(default=5, ge=1, le=20, description="返回数量 1-20")
```

**Response 200**:
```python
class ChunkResponse(BaseModel):
    chunk_id: str
    text: str
    score: float
    metadata: dict

class RetrieveResponse(BaseModel):
    chunks: list[ChunkResponse]
    total: int
```

**处理流程**:
1. 接收 RetrieveRequest
2. 调用 EmbeddingService.embed_query(request.query) 获取查询向量
3. 调用 ChromaDBStore.query(query_embedding, top_k=request.top_k)
4. 将 QueryResult[] 映射为 ChunkResponse[]
5. 返回 RetrieveResponse

**错误场景**:
- 缺少 query → 422（Pydantic 自动校验）
- ChromaDB 异常 → 500

#### GET /api/health（扩展版）

**Response 200**:
```json
{
  "status": "healthy",
  "chromadb": {
    "connected": true,
    "document_count": 3420
  },
  "embedding": {
    "available": true
  }
}
```

**处理流程**:
1. 尝试 ChromaDBStore.count() 判断连接状态
2. 检查 DashScopeEmbedding 是否可初始化（配置有 api_key）
3. 组装响应

**错误场景**:
- ChromaDB 未连接 → status="unhealthy", chromadb.connected=false
- ChromaDB 为空 → status="healthy", document_count=0
