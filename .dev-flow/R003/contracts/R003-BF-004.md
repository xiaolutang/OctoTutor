### 数据模型设计

#### SectionBoundary（章节边界）
```python
@dataclass
class SectionBoundary:
    title: str          # 章节标题文本（如 "1.1 集合"）
    level: int          # 层级: 1=章, 2=节, 3=习题/补充, 4=子节
    start_pos: int      # 在文本中的起始字符位置
    end_pos: int        # 在文本中的结束字符位置
    page: int           # 所在页码
    section_index: int  # 该页内第几个章节（0-based）
```

#### ChunkMetadata（分块元数据）
```python
@dataclass
class ChunkMetadata:
    book: str           # 书名
    chapter: str        # 章名（level=1 标题）
    section: str        # 节名（level=2 标题）
    page: int           # 页码
    chunk_type: str     # "parent" | "child"
    has_formula: bool   # 是否含 LaTeX 公式
    parent_id: str      # parent chunk 的 ID
    child_index: int    # child 在 parent 内的序号（0-based）
```

#### Chunk（分块结果）
```python
@dataclass
class Chunk:
    chunk_id: str       # 唯一标识
    text: str           # 分块文本内容
    metadata: ChunkMetadata
```

### 算法设计

#### StructureParser（章节识别）
1. 正则模式匹配章节标题：
   - `第X章...` → level=1（章）
   - `X.X ...` → level=2（节）
   - `习题X.X` → level=3（习题）
   - `X.X.X ...` → level=4（子节）
2. 按出现位置排序，计算每个 section 的 end_pos（到下一个 section 的 start_pos 或文本末尾）
3. 跟踪当前所在章节上下文（章名、节名），用于填充元数据

#### MathChunker（分块）
1. 以 level=2 小节为 Parent 边界，收集该 section 范围内的全部文本
2. 生成 Parent Chunk（完整小节内容）
3. 对 Parent 文本进行 Child 切分：
   - 目标大小: 512 token（约 1024 中文字符）
   - 重叠: 50 token（约 100 中文字符）
   - 在句子边界切分（句号/问号/感叹号/换行）
   - 单句超 512 token 时整个保留
4. 每条 Chunk 携带完整 metadata

#### 句子边界切分算法
```
1. 预处理: 按句子边界字符（。？！\n）将文本切分为 sentences[]
2. 从头开始累积 sentences:
   a. 当前累积字符数 < 1024 → 继续添加 sentence
   b. 当前累积字符数 >= 1024 → 当前累积为一个 child，回退 100 字符对应的 sentences 作为下一个 child 的起始
   c. 单个 sentence > 1024 → 整个作为一个 child
3. child_index 从 0 递增
```

#### Chunk ID 生成规则
```
格式: {书名}::{章节标识}::{定位}::{类型}

章节标识: 章节标题去空格和标点 (如 "1.1 集合" → "1.1集合")
定位:     p{页码}_s{该页第几个章节}
类型:     parent | child::{序号}

示例:
  Parent: 必修第一册::1.1集合::p12_s0::parent
  Child:  必修第一册::1.1集合::p12_s0::child::0
  Child:  必修第一册::1.1集合::p12_s0::child::1
```

#### has_formula 检测
检查文本是否包含 LaTeX 标记：`$...$`、`$$...$$`、`\begin{equation}`、`\[`、`\(` 等。

## risk_negotiation

| 风险标签 | 风险描述 | 缓解措施 |
|---------|---------|---------|
| regex | 章节标题格式多样，正则可能匹配不全 | 使用多组正则模式，覆盖常见的章节标题格式；未匹配的文本归入最近的上层章节 |
| edge_case | 极短/极长小节导致分块异常 | Parent 保留完整内容不受限制；单句超限整个保留；空小节不生成 Chunk |
| token_estimate | 中文字符数近似 token 数可能有误差 | 使用字符数作为 token 近似（中文 ~2 字符/token），512 token ≈ 1024 字符，后续可替换为精确 tokenizer |
