### 评估指标计算逻辑

#### Hit Rate@K
```
对每条评估问题:
1. 取 top-K 结果的 (book, page) 列表
2. 用 retrieval_truth.check_hit(results[:K]) 判定是否命中
Hit Rate@K = 命中条数 / 总条数
```

#### MRR (Mean Reciprocal Rank)
```
对每条评估问题:
1. 取 top-MAX_K 结果，逐位检查 (book, page)
2. 找到第一个满足 retrieval_truth 任一 source 命中的排名位置 rank
3. 该条 MRR 得分 = 1 / rank
4. 未命中 = 0
MRR = 所有条目得分之和 / 总条数
```

注意：MRR 使用 ANY 语义判定（找第一个 source 命中的位置），与 check_hit 的 ALL 模式无关。
