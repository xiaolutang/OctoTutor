### 接口设计

#### 数据模型
```python
@dataclass
class EvalSource:
    """评估集单个来源定义

    Attributes:
        book: 书名（如 "必修第一册"）
        page_start: 起始页码
        page_end: 结束页码
    """
    book: str
    page_start: int
    page_end: int


@dataclass
class RetrievalTruth:
    """检索真值定义

    Attributes:
        mode: "ANY" | "ALL"
            ANY: top-K 中任一 source 命中即算 Hit
            ALL: top-K 中全部 source 至少各命中一条才算 Hit
        sources: 期望命中的来源列表
    """
    mode: str  # "ANY" | "ALL"
    sources: list[EvalSource]


@dataclass
class EvalItem:
    """评估集单条数据

    Attributes:
        id: 唯一标识（如 "q001"）
        question: 查询问题文本
        retrieval_truth: 检索真值
    """
    id: str
    question: str
    retrieval_truth: RetrievalTruth
```

#### 评估集加载工具
```python
class EvalSetLoader:
    """评估集加载和验证工具

    Args:
        eval_dir: 评估集 JSON 文件所在目录，默认 "data/evaluation"
    """

    def __init__(self, eval_dir: str = "data/evaluation") -> None:
        ...

    def load(self, filename: str = "eval_set.json") -> list[EvalItem]:
        """加载评估集 JSON 并转换为 EvalItem 列表

        Args:
            filename: 评估集文件名

        Returns:
            EvalItem 列表

        Raises:
            FileNotFoundError: 文件不存在
            ValueError: JSON 格式错误或数据校验失败
        """
        ...

    def validate(self, items: list[EvalItem]) -> EvalSetValidation:
        """验证评估集数据完整性

        检查项：
        1. 每个 item 的 id 唯一
        2. question 非空
        3. retrieval_truth.mode 为 ANY 或 ALL
        4. sources 非空，book/page_start/page_end 合理
        5. page_start <= page_end
        6. 覆盖每本书至少 N 条

        Args:
            items: 待验证的 EvalItem 列表

        Returns:
            EvalSetValidation 验证结果
        """
        ...


@dataclass
class EvalSetValidation:
    """评估集验证结果

    Attributes:
        total_items: 总条目数
        unique_ids: ID 是否唯一
        books_covered: 覆盖的书名集合
        min_items_per_book: 每本书最少条目数
        errors: 验证错误列表
        warnings: 验证警告列表
        passed: 是否通过全部验证
    """
    total_items: int
    unique_ids: bool
    books_covered: set[str]
    min_items_per_book: int
    errors: list[str]
    warnings: list[str]
    passed: bool
```

### 评估集 JSON 格式
```json
[
  {
    "id": "q001",
    "question": "什么是函数？函数的定义是什么？",
    "retrieval_truth": {
      "mode": "ANY",
      "sources": [
        {
          "book": "必修第一册",
          "page_start": 67,
          "page_end": 75
        }
      ]
    }
  }
]
```

### 评估集内容规划（25 条）

每本书 5 条，覆盖核心知识点：

#### 必修第一册（集合、函数概念、基本初等函数）
- 集合的定义与表示
- 集合的运算（交集、并集、补集）
- 函数的定义与三要素
- 单调性与奇偶性
- 指数函数与对数函数

#### 必修第二册（三角函数、平面向量、三角恒等变换）
- 任意角与弧度制
- 三角函数的定义
- 平面向量的线性运算
- 向量的数量积
- 两角和与差的三角函数

#### 选择性必修第一册（空间向量、直线和圆、圆锥曲线）
- 空间向量及其运算
- 直线的方程
- 圆的方程
- 椭圆的标准方程
- 双曲线与抛物线

#### 选择性必修第二册（数列、导数）
- 数列的概念
- 等差数列
- 等比数列
- 导数的概念
- 导数的应用（单调性、极值）

#### 选择性必修第三册（计数原理、统计、概率）
- 两个计数原理
- 排列与组合
- 二项式定理
- 随机抽样与统计图表
- 概率的基本性质

## contract_alignment

### 与已有模块的接口
- ChunkMetadata.book 字段格式与评估集 eval_set.json 中的 book 字段需保持一致
- 评估集数据将作为 R003-BB-011（检索质量评估）的输入
- EvalItem.retrieval_truth.sources[].book 对应 ChunkMetadata.book
- EvalItem.retrieval_truth.sources[].page_start/page_end 对应 ChunkMetadata.page 的范围

### 与架构宪法对齐
- ChromaDB 嵌入式运行（评估集不直接操作 ChromaDB）
- 评估集 JSON 存放在 data/evaluation/ 目录
- Backend 是评估能力的唯一承载者
