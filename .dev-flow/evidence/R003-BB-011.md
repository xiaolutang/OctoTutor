## 关键设计决策

1. **MRR 使用 ANY 语义**：`_find_first_rank` 遍历结果列表，找第一个落在任一 source 范围内的位置，与 check_hit 的 ALL 模式判定独立
2. **Hit Rate@K 分 mode 处理**：ANY mode 用 first_rank <= K 判定；ALL mode 直接用 check_hit 的结果（因为 max_k >= K）
3. **按书分组取第一个 source 的 book**：简化处理，一条评估问题只归属一本书
