### 设计决策记录

#### OCR 使用 DashScope MultiModalConversation
- 选择 `MultiModalConversation.call` 而非单独的 OCR API
- 模型: `qwen-vl-max`
- Prompt 设计: 要求输出 Markdown+LaTeX 格式，行内公式 $...$，独立公式 $$...$$
- 原因: qwen-vl 系列对数学公式识别效果好，可直接输出 LaTeX

#### 重试策略
- OCR 重试 2 次（共 3 次尝试），指数退避（1s, 2s）
- 失败后跳过该页（content=""），不抛异常，不阻塞整本 PDF
- 与 Embedding 模块（重试 3 次）保持一致的策略模式

#### 缓存格式
- 使用 .md 文件存储 OCR 结果（Markdown+LaTeX）
- 缓存路径: `data/parsed/{书名}/page_{N}.md`
- 空缓存文件视为无效（content.strip() 为空时返回 None）

#### PNG 渲染
- DPI 150（平衡清晰度和文件大小）
- 使用 PyMuPDF 的 `get_pixmap(matrix=fitz.Matrix(zoom, zoom))`
- zoom = DPI / 72（PDF 默认 72 DPI）
