## 实现详情

### IngestionStats 数据类
- total_books: int — 成功入库的书籍数量
- total_pages: int — 处理的总页数
- total_chunks: int — 入库的总 chunk 数量
- ocr_cache_hits: int — OCR 缓存命中次数
- ocr_calls: int — OCR 实际调用次数
- errors: list[str] — 错误信息列表
- duration_seconds: float — 总耗时（秒）

### IngestionPipeline 编排逻辑
1. `_scan_pdfs(book_name)` — 扫描 data/raw/ 下 PDF 文件，支持全量或指定书名
2. `_ingest_book(pdf_path)` — 单本书入库流程：
   - 幂等删除：ChromaDBStore.delete(where={"book": book_name})
   - PDFReader.read_pdf() → PageResult[]
   - 汇总页面 Markdown → 全文
   - StructureParser.parse() → SectionBoundary[]
   - MathChunker.chunk() → Chunk[]
   - DashScopeEmbedding.embed() → 向量[]
   - ChromaDBStore.upsert(chunks, embeddings)
3. `run(book_name=None)` — 逐本处理 + 统计汇总

### 幂等策略
- 入库前 ChromaDBStore.delete(where={"book": book_name}) 删除旧数据
- OCR 缓存天然幂等（PDFReader 内部 parsed/ 目录缓存）
- 重复运行 chunks 数量一致

### CLI 入口 (__main__.py)
- `python -m ingestion` → 全量入库
- `python -m ingestion --book 必修第一册` → 指定书籍入库
- 从 config.settings 加载配置构建依赖
- 输出格式化统计信息

### 错误处理
- PDF 不存在 → FileNotFoundError 捕获，记录 errors
- Embedding 失败 → RuntimeError 捕获，记录 errors
- 单本书失败不阻塞其他书处理
- 空 PDF/无 chunks → 正常完成，不报错
