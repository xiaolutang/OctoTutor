## 设计决策

1. **不可重试错误处理**: ValueError（如维度不匹配）不属于瞬时错误，不应重试，直接抛出。只有网络错误、API 服务端错误等瞬时错误才触发重试。
2. **默认模型**: 使用 config.py 中定义的 `text-embedding-v3`，支持通过参数覆盖为 `tongyi-embedding-vision-flash` 或其他模型。
3. **embed_query**: 独立方法，传入 `text_type=query`，DashScope API 对查询文本和文档文本使用不同的优化策略。
4. **批量结果拼接**: 使用 `all_embeddings[batch_start + i] = embedding` 确保分批结果放回正确位置。
